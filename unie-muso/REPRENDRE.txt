CONSTRUIRE
----------
HTML (un seul fichier autonome, ~1,1 Mo) :
    cd unie-muso && node build.js            -> dist/UNIE-MUSO.html

APK Android (SDK : platform 34, build-tools 34 ; Gradle 8.14 ; JDK 17) :
    cp dist/UNIE-MUSO.html android/app/src/main/assets/
    cd android
    (mettre uniemuso.keystore dans android/ et le mot de passe dans src/private/keystore-pass.txt)
    export UNIE_KEYSTORE=$PWD/uniemuso.keystore UNIE_KEYSTORE_PASS=$(cat ../src/private/keystore-pass.txt)
    gradle --no-daemon assembleRelease       -> app/build/outputs/apk/release/app-release.apk
    Avant chaque nouvel APK : augmenter versionCode / versionName dans android/app/build.gradle.
    (Installer le SDK demande l'accès réseau à dl.google.com.)

Windows :
    cp dist/UNIE-MUSO.html electron/app/
    cd electron && npm install && npx electron-builder --win dir --x64 && node set-icon.js
    Puis : release/win/UNIE-MUSO/ = contenu de electron/release/win-unpacked + DESINSTALLER.bat,
    à côté : INSTALLER.bat + LISEZ-MOI.txt, le tout zippé en UNIE-MUSO-Windows.zip.
    Version à changer dans : electron/package.json, electron/set-icon.js, windows/INSTALLER.bat.
    (L'installateur NSIS ne se construit pas ici : Wine plante. D'où INSTALLER.bat.)

POINTS TECHNIQUES IMPORTANTS
----------------------------
- Stockage : localStorage (clés uniemuso-*) + copie native dans Documents/UNIE-MUSO
  (téléphone et PC). Si le stockage du navigateur est vide, restoreFromNative() recharge
  le fichier natif.
- Depuis la 3.6 : l'APK sert la page sur https://appassets.androidplatform.net/assets/
  et Windows sur app://unie-muso/ (adresses sécurisées exigées par Firebase).
  Au premier lancement de la 3.6, les données reviennent du dossier Documents/UNIE-MUSO.
- APK 3.6.1 : ajout de la permission INTERNET (absente avant : le téléphone affichait
  « Connexion Internet instable »). Nouvel essai en ligne toutes les 20 s et au retour
  dans l'application ; le code d'erreur Firebase est affiché dans le message.
- 3.6.3 : notifications système (téléphone, PC) pour ce qui arrive du serveur
  (notifyRemoteChanges dans 09-online.js) : annonce -> tous ; message, suggestion,
  demande de prêt -> comité ; réponse, décision de prêt -> le membre concerné.
  Jamais pour ses propres écrits, ni pour l'historique sur un appareil neuf.
- 3.7.0 : notifications sur le téléphone MÊME APPLICATION FERMÉE, sans carte ni serveur payant.
  L'appli qui envoie écrit dans des « boîtes » Firestore : notifs/{M007 | comite | admin} = { last }
  + notifs/{boîte}/ev/{id} = { at, t, b, by, eid } (collabEvents / sendBoxEvent, 09-online.js).
  Le service Android PushService (premier plan, « UNIE-MUSO actif ») lit seulement « last »
  de ses boîtes toutes les 90 s (10 min de 22 h à 6 h), puis les nouveaux événements
  (logique dans PushCore.java, testable sur PC : javac + org.json contre l'émulateur).
  Quota gratuit Firestore : 50 000 lectures/jour ; 19 téléphones ≈ 13 000/jour.
  Les règles Firestore doivent contenir le bloc « notifs » (firebase/firestore.rules).
  Doublons évités : la page notifie quand elle est à l'écran, le service sinon.
- 3.6.4 : envoi plus rapide depuis le PC. pushAll envoie d'abord messages / annonces /
  demandes (pushCollab) puis les grandes listes (pushShared) ; un envoi demandé pendant un
  autre n'est plus perdu (ONLINE.pushAgain). Au retour au premier plan après plus de 20 s,
  la connexion Firestore est rouverte (disableNetwork puis enableNetwork).
- Rôles : admin (trésorier), éditeur (un membre du comité choisi dans Paramètres,
  Présidente par défaut), comité, membre. Seuls admin et éditeur modifient.
- En ligne : comptes « code@uniemuso.app », admin « admin@uniemuso.app » ; refus de passer
  en ligne tant que le mot de passe admin est « admin ». Données partagées en morceaux
  dans la collection « db » ; messages, suggestions, annonces, demandes : un document chacun.
- Comptabilité : plan comptable du trésorier (classes 1, 2, 3, 4, 5, 7, 6). Contrôlé
  identique au classeur Excel au 29/10/2026 (balance 265 450 / 265 450, bilan 241 900).
- Interface : toujours « membre » (jamais « sociétaire »), police 13 px, pas d'emoji
  (sauf 📥 sur la bannière d'import), pas de fond crème ni de terracotta.
